# 座椅加热咨询：未绑定车型时的安全答复规范

## 文档属性

- 文档类型：知识库答复规范
- 来源：项目维护者编写
- 适用范围：用户未提供品牌、车型、年款、配置，或知识库中没有对应官方手册时
- 不适用范围：不得替代任何具体车辆的《用户手册》、售后公告或功能配置表

## 核心规则

“座椅加热有哪几种开启方式”“座椅加热怎么开”这类问题的准确答案依赖具体车辆。不同品牌、年款和配置的控制入口可能不同，某项功能也可能未配备。因此，在没有对应车型官方资料时，系统不得回答固定的开启方式数量，也不得把其他车型的中控屏、实体按键或 App 操作方式套用到当前车辆。

## 推荐答复

若知识库没有对应车型手册，应回答：

> 当前知识库没有这辆车的官方座椅加热操作资料，无法确认具体开启方式或档位。请提供品牌、车型、年款和配置，或上传该车用户手册中“座椅 / 空调 / 舒适功能”章节；我会据此给出带来源的操作步骤。

## 入库与引用要求

每一份可用于回答实际操作的问题的资料，应至少包含：品牌、车型、年款、配置或适用条件、文档版本或发布日期、官方来源链接或手册页码。若资料仅说明某一功能“可能支持”，必须保留条件描述，不能推断所有车型均具备该功能。

## 处理流程

1. 先识别问题是否涉及车型专属功能，例如座椅加热、座椅通风、远程空调、驾驶辅助或 OTA。
2. 检查查询中是否带有品牌、车型、年款、配置等限定信息。
3. 仅检索相同车型或明确适用的官方资料。
4. 若没有足够支持资料，返回“资料不足”，并提示用户补充车型信息或上传官方手册；不要以泛化网页或其他车型资料补全答案。
