# 智能座驾知识库：车型手册入库标准

## 目标

让每条面向真实车辆操作的答案可追溯、可限定适用范围，并避免跨车型串用知识。

## 优先级

1. 车辆品牌官方《用户手册》或车机帮助中心。
2. 品牌官方 App 使用说明、官方售后技术公告或版本说明。
3. 经审核的经销商培训资料，仅可作为辅助来源，且必须标注其非原厂属性。
4. 论坛、聚合问答、营销文章不得作为唯一依据；若保留，只能用于发现候选问题，不能单独支撑操作结论。

## 单篇资料的最小元数据

- 品牌、车型、年款、配置级别或适用车型范围
- 功能名称与同义词
- 官方来源链接、手册文件名和页码，或版本号与发布日期
- 内容生效范围：地区、车机系统版本、App 版本或硬件条件
- 录入日期与复核人

## 座椅舒适功能的覆盖清单

对于每一车型，建议单独收录并标注来源页码：

- 座椅加热：前排/后排可用性、控制入口、档位、关闭条件
- 座椅通风：可用座位、控制入口、与加热是否互斥
- App 远程控制：是否支持、账号与网络前置条件、功能限制
- 安全限制：儿童座椅、车辆状态、故障提示和售后处理入口

## 验收规则

导入后为每个车型建立至少五个问答：开启、关闭、档位、适用座位、异常或限制。每个问题都要绑定对应文档 ID；缺少对应资料的问题必须测试为“资料不足，无法回答”。
