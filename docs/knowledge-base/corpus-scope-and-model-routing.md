# 智能座驾知识库范围与车型分流规则

## 当前产品定位

本项目当前定位为**通用智能座舱知识助手与 RAG 评测示例**，覆盖驾驶辅助、座椅舒适功能、HUD、语音交互、OTA、胎压与用车安全等主题。

现有预置资料来自多个品牌和公开网页，未形成同一品牌、车型、年款与配置的一致证据链。因此，知识库不能把某个品牌或车型的操作步骤回答为“所有车辆”的通用做法。

## 可以回答的问题

- 概念解释：例如 ACC、AEB、HUD、座椅通风的功能边界与常见限制。
- 用车安全与排查建议：前提是资料中存在直接支持的原文，并在答案中保留限制条件。
- 知识库自身的覆盖范围、资料来源、缺失项与补充方式。

## 必须进行车型分流的问题

以下问题属于车型专属操作，必须同时具备品牌、车型、年款、配置与对应官方资料，才能给出步骤、档位、按钮位置或功能可用性结论：

- 座椅加热、通风、按摩及后排座椅功能
- 远程 App 控车、空调预约、钥匙和账号功能
- ACC、AEB、泊车、车道辅助等驾驶辅助的开启条件与速度范围
- HUD 显示、车机菜单路径、OTA 升级入口和故障码处理

## 缺少车型资料时的标准答复

若用户未给出车型信息，或知识库中没有同车型官方手册，应答复：

> 当前资料覆盖多个品牌，未包含该车的官方操作说明，无法确认具体按钮、菜单、档位或适用条件。请提供品牌、车型、年款和配置，或上传用户手册对应章节。

## 后续入库策略

在完成“车型字段过滤”之前，只增加通用概念、安全边界和资料治理类内容；不混入多个品牌的具体操作说明。完成过滤后，再按“一个品牌 / 车型 / 年款 / 配置一组资料 + 一组评测题”的方式扩展。
